# Хоткеи

> Внутри nvim: `:Keys` — открывает этот справочник.
> `Space+?` — поиск по всем активным хоткеям через Telescope.
> `?` в файловом дереве — хоткеи дерева.

---

## Навигация

| Хоткей | Действие |
|---|---|
| `Ctrl+T` | Найти файл (fuzzy) |
| `Alt+F` | Поиск текста внутри файлов |
| `Space+e` | Открыть / закрыть файловое дерево |
| `Space+E` | Показать текущий файл в дереве |
| `Space+?` | Поиск по всем хоткеям |
| `Tab` | Следующий буфер |
| `Shift+Tab` | Предыдущий буфер |
| `Space+x` | Закрыть текущий буфер |

---

## Файловое дерево

| Хоткей | Действие |
|---|---|
| `a` | Создать файл |
| `A` | Создать папку |
| `r` | Переименовать |
| `d` | Удалить |
| `m` | Переместить |
| `y` | Копировать |
| `x` | Вырезать |
| `p` | Вставить |
| `o` | Открыть в Finder / файловом менеджере |
| `R` | Обновить дерево вручную |
| `?` | Все хоткеи дерева |

## LSP

| Хоткей | Действие |
|---|---|
| `gd` | Перейти к определению |
| `K` | Показать документацию |
| `gr` | Показать все ссылки |
| `Space+rn` | Переименовать символ |
| `Space+ca` | Код-экшены (quick fix, refactor) |

## Автодополнение

| Хоткей | Действие |
|---|---|
| `Ctrl+Space` | Вызвать вручную |
| `Enter` | Подтвердить |
| `Tab / Shift+Tab` | Навигация по вариантам |
| `Ctrl+e` | Закрыть |
| `Ctrl+b / Ctrl+f` | Скролл документации |

## Git

| Хоткей | Команда | Действие |
|---|---|---|
| `Space+gs` | `:Git` | Статус / коммит (Neogit) |
| `Space+gd` | `:Git diff` | Просмотр diff |
| `Space+gl` | `:Git log` | История коммитов |
| `Space+gb` | `:Branch` | Переключить ветку |
| `Space+gn` | — | Создать новую ветку |
| `Space+gp` | — | Push в origin |
| `Space+gu` | — | Pull |

В пикере веток (`Space+gb`):

| Хоткей | Действие |
|---|---|
| `Enter` | Переключиться на ветку |
| `Ctrl+N` | Создать ветку из введённого имени |
| `Ctrl+P` | Запушить текущую ветку |
| `Ctrl+U` | Pull |

## Запуск проектов

| Хоткей | Команда | Действие |
|---|---|---|
| `Space+rr` | `:Run` | Пикер конфигураций |
| `Space+rs` | `:Stop` | Остановить всё |
| `Space+rt` | `:Term` | Открыть терминал |
| `Space+rp` | `:RunSetup` | Создать / открыть run.json |
| `Ctrl+\` | — | Свернуть / развернуть терминал |
| `Esc` (в терминале) | — | Выйти из режима ввода |
