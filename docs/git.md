# Git-интеграция

## Обзор

Git-функционал разделён на три уровня: строка состояния (gitsigns), полноэкранный UI (Neogit), просмотр diff и истории (DiffView).

## Хоткеи

| Хоткей | Описание |
|---|---|
| `Space+gs` | Git статус / коммит (Neogit) |
| `Space+gd` | Diff текущего состояния |
| `Space+gl` | История коммитов |
| `Space+gb` | Переключить ветку (Telescope) |
| `Space+gn` | Создать новую ветку |
| `Space+gp` | Push в origin |
| `Space+gu` | Pull |

## Neogit — статус и коммиты

`:Git` или `Space+gs` открывает Neogit — интерактивный Git UI.

Основные операции внутри Neogit:
- `s` — stage файл / hunk
- `u` — unstage
- `cc` — создать коммит
- `?` — показать все доступные действия

## Переключение веток

`Space+gb` или `:Branch` открывает Telescope-пикер со списком веток.

Дополнительные действия в пикере:

| Клавиша | Действие |
|---|---|
| `Enter` | Переключиться на ветку |
| `Ctrl+N` | Создать новую ветку из введённого имени |
| `Ctrl+P` | Запушить текущую ветку |
| `Ctrl+U` | Pull |

## DiffView — просмотр изменений

| Команда | Описание |
|---|---|
| `Space+gd` | Diff всех несохранённых изменений |
| `Space+gl` | История файла / проекта |
| `:DiffviewOpen` | Открыть diff вручную |
| `:DiffviewFileHistory` | История коммитов |
| `:DiffviewClose` | Закрыть |

## Gitsigns — отметки в редакторе

В левой колонке (gutter) показываются изменения относительно HEAD:

| Символ | Значение |
|---|---|
| `+` | Добавленная строка |
| `~` | Изменённая строка |
| `_` | Удалённая строка |

## Команды

| Команда | Описание |
|---|---|
| `:Git` | Открыть Neogit |
| `:Git diff` | Открыть DiffView |
| `:Git log` | История файла |
| `:Branch` | Пикер веток |
