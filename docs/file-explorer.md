# Файловое дерево

## Обзор

Файловое дерево реализовано через **neo-tree**. Автоматически открывается при старте если nvim запущен без файла. Следит за изменениями файловой системы в реальном времени (libuv file watcher) — файлы добавленные извне появляются автоматически.

## Открытие и навигация

| Хоткей | Описание |
|---|---|
| `Space+e` | Открыть / закрыть дерево |
| `Space+E` | Показать текущий файл в дереве (reveal) |
| `Enter` | Открыть файл или раскрыть папку |
| `?` | Показать все доступные команды |

Кнопка `[ reveal in tree]` в строке состояния делает то же что `Space+E`.

## Операции с файлами

| Клавиша | Действие |
|---|---|
| `a` | Создать файл (с вводом пути) |
| `A` | Создать папку |
| `r` | Переименовать |
| `d` | Удалить (с подтверждением) |
| `m` | Переместить |
| `y` | Копировать в буфер |
| `x` | Вырезать |
| `p` | Вставить |

## Интеграция с системой

| Клавиша | Действие |
|---|---|
| `o` | Открыть папку в Finder (macOS) / файловом менеджере (Linux) |

Кнопка `[ open in Finder]` / `[ open folder]` в строке состояния открывает папку выбранного узла.

## Принудительное обновление

Нажми `R` в окне дерева для мгновенного ручного обновления (обычно не нужно — watcher обновляет сам).

## Настройки

По умолчанию:
- Показываются dotfiles (`.env`, `.gitignore` и т.д.)
- Показываются файлы из `.gitignore`
- Автоматическое следование за текущим файлом отключено (не перерисовывает дерево при каждом переключении буфера)
