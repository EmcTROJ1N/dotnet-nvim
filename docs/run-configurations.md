# Запуск проектов

## Обзор

Запуск проектов работает через именованные конфигурации, которые хранятся в `.neovim/run.json` в корне проекта. Аналог Run Configurations в IDE.

## Быстрый старт

```
Space → r → r     открыть пикер конфигураций
Space → r → s     остановить все запущенные процессы
Space → r → t     открыть терминал
Space → r → p     создать / открыть run.json (:RunSetup)
```

## Создание конфигурации

Запусти `:RunSetup` — если `.neovim/run.json` ещё нет, он автоматически найдёт `.csproj` и `package.json` в проекте и создаст шаблон. Если файл уже есть — просто откроет его для редактирования.

## Формат run.json

```json
{
  "_help": {
    "cmd":      "Shell-команда запуска",
    "cwd":      "Рабочая директория относительно корня проекта",
    "env":      "Переменные окружения { \"KEY\": \"value\" }",
    "compound": "Список имён конфигураций для одновременного запуска",
    "default":  "Имя конфига который выделяется первым в пикере"
  },

  "configurations": [
    {
      "name": "API",
      "cmd":  "dotnet run",
      "cwd":  "src/Api",
      "env":  {
        "ASPNETCORE_ENVIRONMENT": "Development"
      }
    },
    {
      "name": "Frontend",
      "cmd":  "npm start",
      "cwd":  "src/ClientApp"
    },
    {
      "name": "API + Frontend",
      "compound": ["API", "Frontend"]
    }
  ],

  "default": "API + Frontend"
}
```

## Поле env — переменные окружения

Используй `env` вместо того чтобы прописывать переменные прямо в команду. Это читаемее и безопаснее.

```json
"env": {
  "ASPNETCORE_ENVIRONMENT": "Development",
  "DATABASE_URL": "Host=localhost;Database=mydb",
  "PORT": "5000"
}
```

> **Важно для ASP.NET Core + SPA:** если приложение в Development-режиме проксирует фронтенд на отдельный порт (например, Angular на :4200), нужно одновременно запустить и API и dev-сервер через compound-конфиг. Иначе статика будет битой.

## Compound — одновременный запуск

Позволяет запустить несколько конфигов одной командой. Каждый процесс открывается в отдельном терминале.

```json
{
  "name": "Полный стек",
  "compound": ["API", "Frontend", "Worker"]
}
```

## Остановка

`:Stop` останавливает все запущенные процессы (из всех конфигураций).

## Автодетект (без run.json)

Если `.neovim/run.json` нет, `:Run` попытается определить тип проекта автоматически:
- Находит `.csproj` с `Sdk.Web` или `OutputType=Exe` → `dotnet watch run --project`
- Находит `package.json` → `npm run dev` или `npm start`

Рекомендуется всегда создавать `run.json` для точного контроля.

## Команды

| Команда | Описание |
|---|---|
| `:Run` | Открыть пикер конфигураций |
| `:Run <имя>` | Запустить конфигурацию по имени |
| `:Run <команда>` | Запустить произвольную shell-команду |
| `:Stop` | Остановить все процессы |
| `:Term` | Открыть пустой терминал |
| `:RunSetup` | Создать или открыть `.neovim/run.json` |
