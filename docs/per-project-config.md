# Per-project конфигурация

## Обзор

Папка `.neovim/` в корне проекта — стандартное место для настроек которые меняются от проекта к проекту. Настройки загружаются автоматически при открытии проекта.

Добавь `.neovim/` в `.gitignore` чтобы личные настройки не попадали в репозиторий:

```bash
echo ".neovim/" >> .gitignore
```

## Файлы

### `.neovim/run.json` — конфигурации запуска

Создаётся через `:RunSetup`. Содержит именованные конфигурации запуска проекта.

→ [Подробнее: Запуск проектов](run-configurations.md)

### `.neovim/ef.json` — настройки EF Core

Создаётся через `:EfSetup`. Содержит пути к migrations-проекту и startup-проекту.

→ [Подробнее: EF Core миграции](ef-migrations.md)

## Автозагрузка

Оба файла загружаются автоматически:
- При старте nvim (`VimEnter`)
- При смене рабочей директории (`DirChanged`)

## Расширение

В будущем в `.neovim/` можно добавлять любые другие настройки специфичные для проекта — например, переопределение форматтера, переменные окружения для дебага, и т.д.
